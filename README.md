# 발음 체크 — 개선판

영어 문장이나 단어를 소리 내어 읽고, 브라우저가 인식한 텍스트를 원문과 비교하여 **다르게 인식된 단어를 찾아 반복 연습**하는 단일 파일 웹앱입니다.

> **중요:** 표시되는 점수는 **원문과 음성인식 텍스트의 일치율**이며, 발음의 음소·강세·억양을 직접 측정한 전문적인 발음 평가 점수가 아닙니다. 음성인식 결과는 브라우저, 기기, 주변 소음, 네트워크, 문맥에 영향을 받을 수 있습니다.

## 파일 구성

```text
발음체크_개선판.html   # 웹앱 본체 (HTML/CSS/JavaScript 포함)
README.md             # 사용 및 운영 안내
```

별도 패키지 설치나 빌드 작업은 필요하지 않습니다.

## 실행 방법

### 권장: HTTPS 주소에서 열기

1. `발음체크_개선판.html`을 정적 웹 호스팅 서비스(예: GitHub Pages)에 게시합니다. GitHub Pages를 사용하는 경우, 필요하면 파일 이름을 `index.html`로 변경합니다.
2. 생성된 **https://** 주소를 Chrome, Edge 또는 지원되는 Safari 브라우저에서 엽니다.
3. 마이크 권한 요청이 나타나면 허용합니다.
4. **스크립트** 메뉴에서 영어 문장·단어를 입력한 뒤 **연습 시작**을 누릅니다.

### PC에서 로컬 테스트

HTML 파일이 있는 폴더에서 다음 명령을 실행하고 `http://localhost:8000/발음체크_개선판.html`에 접속할 수 있습니다.

```bash
python -m http.server 8000
```

Python이 설치되어 있어야 하며, `localhost`는 일반적으로 브라우저에서 보안 컨텍스트로 취급됩니다. 다만 **음성인식 API 지원 여부는 브라우저·운영체제마다 다릅니다.** 파일을 더블클릭하여 `file://` 주소에서 여는 방식은 마이크 음성인식이 제한될 수 있으므로 권장하지 않습니다.

## 기본 사용법

1. **스크립트:** 영어 글을 붙여넣습니다. 여러 문장은 문장부호를 기준으로 나누고, 단어 하나씩 연습할 경우 한 줄에 한 단어를 입력합니다. **예시 불러오기**로 테스트할 수도 있습니다.
2. **연습:** **읽기 시작**을 누르고 표시된 영어를 읽습니다. 필요하면 **다 읽었으면 누르기**로 녹음을 종료합니다.
3. **결과 확인:** 일치율과 일치·애매·대체·누락·추가 단어 수를 확인합니다. 원문의 다르게 인식된 단어는 강조 표시됩니다.
4. **단어 재연습:** 강조된 단어를 누르고 **단어 듣기** 또는 **단어만 읽기**를 선택합니다.
5. **반복 연습:** **다시 읽기**를 누르면 같은 문장의 새 결과가 기록됩니다. 이전·다음 버튼이나 아래 항목 목록을 이용해 이동할 수 있습니다.
6. **약한 단어:** 누적해서 다르게 인식된 단어를 확인하고 **상위 10개 단어로 연습**을 이용합니다.

## 이번 개선판에 반영된 6가지

| 항목 | 변경 내용 |
|---|---|
| 1. 판정 신뢰성 | 최대 3개의 음성인식 후보를 참고하여 다른 후보에서 일치한 단어는 **애매**로 표시합니다. 추가로 인식된 단어도 일치율 산식의 분모에 포함합니다. |
| 2. 반복 연습 기록 | 같은 문장을 여러 차례 읽으면 시도별 점수를 누적하고, 최근 최대 8개 점수와 최초·최근 점수 차이를 표시합니다. |
| 3. 비교 알고리즘 | 최소 편집 거리 기반 정렬로 **일치·대체·누락·추가**를 구분합니다. |
| 4. 단어 교정 | 강조된 단어를 누르면 해당 단어의 원문 음성을 듣고 별도로 음성인식 연습을 할 수 있습니다. |
| 5. 진행 현황 | **완료 항목 / 전체 항목**, **현재 각 항목의 최근 점수 평균**, **90% 미만 재연습 대상 수**를 표시합니다. |
| 6. 모바일 사용성 | 좁은 화면에서 연습 결과, 버튼, 단어 선택 영역을 조정한 반응형 레이아웃을 적용했습니다. |

## 점수와 표시 이해하기

- **일치:** 기본 음성인식 후보의 단어가 원문과 일치합니다.
- **애매:** 기본 후보에서는 일치하지 않지만 다른 음성인식 후보에서 일치합니다.
- **대체:** 원문 단어가 다른 단어로 인식되었습니다.
- **누락:** 원문의 단어가 인식 결과에 나타나지 않습니다.
- **추가:** 원문에 없는 단어가 인식 결과에 나타납니다.

**일치율 = 기본 후보에서 일치한 단어 수 ÷ (원문의 단어 수 + 추가 인식된 단어 수) × 100** (반올림). 애매 단어는 별도로 표시되며 점수의 일치 단어 수에 포함하지 않습니다.

예를 들어 원문에 10개 단어가 있고 8개가 일치하며 추가 인식된 단어가 1개라면 일치율은 약 **73%**입니다. 단어별 재연습은 해당 단어의 결과를 확인하는 기능이며, 원래 문장의 점수를 자동으로 바꾸지는 않습니다.

## 언어 및 읽기 설정

- 인식할 영어: **미국(en-US) / 영국(en-GB) / 호주(en-AU) / 캐나다(en-CA)**
- 원문 읽기 속도: **느리게(0.7) / 조금 느리게(0.9) / 보통(1.0)**
- 원문 듣기는 브라우저의 음성 합성(`speechSynthesis`) 기능을 사용합니다. 제공되는 목소리는 기기에 따라 다를 수 있습니다.

## 저장 및 초기화

- 연습 스크립트, 항목별 최근 결과, 문장별 연습 이력, 약한 단어 통계, 설정을 브라우저 저장소에 저장합니다. 특정 앱 환경에서는 `window.storage`를 우선 이용하고, 일반 브라우저에서는 `localStorage`를 이용합니다. 저장소를 사용할 수 없는 경우 현재 페이지에서만 임시로 유지됩니다.
- **새 스크립트로 연습 시작**하면 이전 스크립트의 항목별 결과와 반복 이력이 초기화되지만 **약한 단어 누적 통계는 남습니다**.
- **약한 단어 → 기록 지우기**는 약한 단어 통계만 삭제합니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 브라우저·기기 사용 등에 따라 기록이 유지되지 않을 수 있습니다. 자동 클라우드 동기화 기능은 없습니다.

## 문제 해결

| 증상 | 확인할 사항 |
|---|---|
| 마이크 버튼이 작동하지 않음 | HTTPS 또는 `http://localhost`로 접속했는지, 사이트 마이크 권한이 허용되었는지 확인하세요. |
| 음성인식을 지원하지 않는다는 안내 | 브라우저를 최신 버전으로 업데이트하고 Chrome·Edge 또는 기기에서 지원되는 Safari로 시도하세요. 지원 범위는 기기별로 다릅니다. |
| 말했는데 아무것도 인식되지 않음 | 마이크 입력 장치, 주변 소음, 음성인식 서비스 연결 상태를 확인하고 다시 읽어보세요. |
| 잘 읽었는데 낮은 점수가 나옴 | 인식 오류 또는 단어 분리·정렬의 영향일 수 있습니다. **원문 듣기**와 비교하고 다시 시도하세요. |
| 기록이 사라짐 | 브라우저 저장소 또는 개인정보 보호 설정, 다른 브라우저·기기 사용 여부를 확인하세요. |

## 기술 구성 및 유의사항

- **HTML + CSS + JavaScript** 단일 파일
- 음성인식: 브라우저 `SpeechRecognition` / `webkitSpeechRecognition` API
- 원문 읽기: 브라우저 `SpeechSynthesis` API
- 비교: 단어 정규화 및 최소 편집 거리 기반 정렬
- 별도 계정, 자체 서버, 외부 JavaScript 라이브러리는 필요하지 않습니다. 단, **브라우저 음성인식 서비스는 자체적으로 네트워크 통신을 사용할 수 있으므로 완전한 오프라인·음성 데이터 비전송 방식으로 간주하면 안 됩니다.**
- 이 버전에는 CSV 내보내기, 자동 다음 문장 이동, 별도 마이크 테스트, 계정·클라우드 동기화 기능을 추가하지 않았습니다.
