# 발음 체크

영어 문장이나 단어를 소리 내어 읽고, 브라우저가 인식한 텍스트를 원문과 비교하여 **다르게 인식된 단어를 찾아 반복 연습**하는 단일 파일 웹앱입니다. 내 목소리를 녹음해 원문 음성과 번갈아 들어볼 수도 있습니다.

> **중요:** 표시되는 점수는 **원문과 음성인식 텍스트의 일치율**이며, 발음의 음소·강세·억양을 직접 측정한 전문적인 발음 평가 점수가 아닙니다. 음성인식 결과는 브라우저, 기기, 주변 소음, 네트워크, 문맥에 영향을 받을 수 있습니다.

## 이 앱으로 연습할 수 있는 것

| 구분 | 내용 |
|---|---|
| 잘 잡아내는 것 | 개별 소리(자음·모음) 차이. 특히 right/light, think/sink, very/berry, sheep/ship 같은 최소대립쌍 |
| 부분적으로 잡아내는 것 | 문장 속 단어 누락·추가, 끝 자음(-s, -ed) 탈락, 약하게 발음한 기능어. 단, 음성인식이 문맥으로 보정해 놓치는 경우가 있습니다. |
| 판정하지 못하는 것 | 강세, 억양, 리듬, 연음의 자연스러움. **내 목소리 듣기**와 **원문 듣기**를 번갈아 들으며 귀로 비교하세요. |

## 파일 구성

```text
index.html   # 웹앱 본체 (HTML/CSS/JavaScript 포함)
README.md    # 사용 및 운영 안내
```

별도 패키지 설치나 빌드 작업은 필요하지 않습니다.

## 실행 방법

### 권장: HTTPS 주소에서 열기

1. `index.html`을 정적 웹 호스팅 서비스(예: GitHub Pages)에 게시합니다.
2. 생성된 **https://** 주소를 Chrome, Edge 또는 지원되는 Safari 브라우저에서 엽니다.
3. 마이크 권한 요청이 나타나면 허용합니다. 음성인식과 녹음 권한이 따로 요청될 수 있습니다.
4. **스크립트** 메뉴에서 영어 문장·단어를 입력한 뒤 **연습 시작**을 누릅니다.

### PC에서 로컬 테스트

HTML 파일이 있는 폴더에서 다음 명령을 실행하고 `http://localhost:8000/index.html`에 접속할 수 있습니다.

```bash
python -m http.server 8000
```

Python이 설치되어 있어야 하며, `localhost`는 일반적으로 브라우저에서 보안 컨텍스트로 취급됩니다. 다만 **음성인식 API 지원 여부는 브라우저·운영체제마다 다릅니다.** 파일을 더블클릭하여 `file://` 주소에서 여는 방식은 마이크 음성인식이 제한될 수 있으므로 권장하지 않습니다.

## 기본 사용법

1. **스크립트:** 영어 글을 붙여넣습니다. 여러 문장은 문장부호를 기준으로 나누고, 단어 하나씩 연습할 경우 한 줄에 한 단어를 입력합니다. **예시 불러오기**로 테스트할 수도 있습니다.
2. **연습:** **읽기 시작**을 누르고 표시된 영어를 읽습니다. 단어 항목은 기본적으로 **"Say ___ again."** 틀 문장으로 표시되며, 회색 글자까지 한 문장으로 읽습니다. 필요하면 **다 읽었으면 누르기**로 녹음을 종료합니다.
3. **결과 확인:** 일치율과 일치·애매·대체·누락·추가 단어 수를 확인합니다. 원문의 다르게 인식된 단어는 강조 표시됩니다.
4. **내 목소리 비교:** **내 목소리 듣기**와 **원문 듣기**를 번갈아 들으며 소리, 억양, 리듬 차이를 비교합니다.
5. **단어 재연습:** 강조된 단어를 누르고 **단어 듣기** 또는 **단어만 읽기**를 선택합니다.
6. **반복 연습:** **다시 읽기**를 누르면 같은 문장의 새 결과가 기록됩니다. 이전·다음 버튼이나 아래 항목 목록을 이용해 이동할 수 있습니다.
7. **약한 단어:** 누적해서 다르게 인식된 단어를 확인하고 **상위 10개 단어로 연습**을 이용합니다. 이 기능은 새 스크립트로 시작하므로 현재 스크립트의 결과와 반복 이력이 초기화됩니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 음성인식 결과 판정 | 최대 3개의 음성인식 후보를 참고하여 다른 후보에서 일치한 단어는 **애매**로 표시합니다. 추가로 인식된 단어도 일치율 산식의 분모에 포함합니다. 브라우저에 따라 후보가 1개만 제공되어 애매 표시가 거의 나타나지 않을 수 있습니다. |
| 동음이의어 허용 | right/write, two/to/too, see/sea처럼 발음이 같은 단어는 일치로 처리합니다. 목록은 코드의 `HOMOPHONES` 배열에서 수정할 수 있습니다. |
| 단어 틀 문장 | 단어 항목을 "Say ___ again."에 넣어 읽게 합니다. 단독 단어보다 인식이 안정적이고, 문맥이 정답을 알려주지 않아 발음 차이가 결과에 더 잘 드러납니다. |
| 내 목소리 녹음 | 읽는 동안 내 목소리를 녹음하여 결과 화면에서 다시 들을 수 있습니다. |
| 반복 연습 기록 | 같은 문장을 여러 차례 읽으면 시도별 점수를 누적하고, 최근 최대 8개 점수와 최초·최근 점수 차이를 표시합니다. |
| 단어 비교 | 최소 편집 거리 기반 정렬로 **일치·대체·누락·추가**를 구분합니다. |
| 단어별 연습 | 강조된 단어를 누르면 해당 단어의 원문 음성을 듣고 별도로 음성인식 연습을 할 수 있습니다. |
| 진행 현황 | **완료 항목 / 전체 항목**, **현재 각 항목의 최근 점수 평균**, **90% 미만 재연습 대상 수**를 표시합니다. |
| 모바일 사용 | 좁은 화면에서 연습 결과, 버튼, 단어 선택 영역에 맞춘 반응형 레이아웃을 제공합니다. |

## 점수와 표시 이해하기

- **일치:** 기본 음성인식 후보의 단어가 원문과 일치합니다. 동음이의어도 일치로 봅니다.
- **애매:** 기본 후보에서는 일치하지 않지만 다른 음성인식 후보에서 일치합니다.
- **대체:** 원문 단어가 다른 단어로 인식되었습니다.
- **누락:** 원문의 단어가 인식 결과에 나타나지 않습니다.
- **추가:** 원문에 없는 단어가 인식 결과에 나타납니다.

**일치율 = 기본 후보에서 일치한 단어 수 ÷ (원문의 단어 수 + 추가 인식된 단어 수) × 100** (반올림). 애매 단어는 별도로 표시되며 점수의 일치 단어 수에 포함하지 않습니다.

예를 들어 원문에 10개 단어가 있고 8개가 일치하며 추가 인식된 단어가 1개라면 일치율은 약 **73%**입니다.

**틀 문장으로 읽은 단어 항목**은 가운데 단어만 채점하므로 점수가 **100% 또는 0%**로 표시됩니다. "Say"와 "again"의 인식 여부나 추가 인식된 단어는 점수에 영향을 주지 않습니다.

단어별 재연습은 해당 단어의 결과를 확인하는 기능이며, 원래 문장의 점수를 자동으로 바꾸지는 않습니다.

## 언어 및 읽기 설정

- 인식할 영어: **미국(en-US) / 영국(en-GB) / 호주(en-AU) / 캐나다(en-CA)**
- 원문 읽기 속도: **느리게(0.7) / 조금 느리게(0.9) / 보통(1.0)**
- **단어 읽기 방식:** **틀 문장(Say ___ again)**(기본) 또는 **단어만**. 문장 항목에는 적용되지 않습니다. 틀 문장을 켜면 **원문 듣기**도 틀 문장 전체를 읽어 줍니다.
- **내 목소리 녹음:** **켜기**(기본) / **끄기**
- **원문 음성 엔진:** 브라우저 기본 음성 또는 **Google Cloud Text-to-Speech**를 선택합니다. Google 음성은 iPad Safari의 기본 음성 대신 Google이 생성한 MP3를 재생합니다.
- **Google 음성:** 여성/남성 목소리를 선택할 수 있습니다. 영어 종류 설정에 따라 해당 언어의 음성이 요청됩니다.

### iPad에서 Google Cloud 음성 사용하기

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 준비하고 **Cloud Text-to-Speech API**를 활성화합니다. Google Cloud의 결제 설정이 필요할 수 있고, 실제 사용량과 음성 모델에 따라 과금될 수 있습니다.
2. 해당 API만 사용할 수 있도록 제한한 **API 키**를 발급합니다. API 키 사용 제한을 반드시 설정하고 Google Cloud에서 할당량·예산 알림을 확인하세요.
3. iPad Safari에서 HTTPS로 게시된 `index.html`을 열고 **연습 → 설정 → 원문 음성 엔진 → Google Cloud TTS**를 선택합니다.
4. API 키를 입력하고 여성/남성 음성, 원문 읽기 속도를 선택합니다.
5. **원문 듣기** 또는 **단어 듣기**를 누르면 Google Cloud에서 음성을 생성하여 재생합니다. Safari에서 자동 재생이 제한되는 경우 화면에 나타나는 오디오 플레이어를 직접 눌러 재생하세요.

**보안 유의:** API 키는 앱의 영구 저장소에 저장되지 않고 현재 열린 페이지에서만 사용됩니다. 페이지를 새로고침하면 재입력이 필요합니다. 다만 정적 웹앱은 API를 브라우저에서 직접 호출하므로 **키가 개발자 도구·네트워크 요청에 노출될 수 있습니다.** 비공개 개인 사용을 전제로 제공한 방식이며, 공개 배포·다중 사용자 용도에는 **인증된 서버 측 중계 API**가 필요합니다. 키를 HTML 파일이나 GitHub 저장소에 직접 써 넣지 마세요. Google Cloud API의 브라우저 접근 정책, API 키 제한 및 요금 정책에 따라 호출이 제한될 수 있습니다.

## 저장 및 초기화

- 연습 스크립트, 항목별 최근 결과, 문장별 연습 이력, 약한 단어 통계, 설정을 브라우저 저장소에 저장합니다. 특정 앱 환경에서는 `window.storage`를 우선 이용하고, 일반 브라우저에서는 `localStorage`를 이용합니다. 저장소를 사용할 수 없는 경우 현재 페이지에서만 임시로 유지됩니다.
- **내 목소리 녹음은 저장되지 않습니다.** 가장 최근 녹음 1개만 현재 페이지의 메모리에 유지되며, 다른 문장을 읽거나 새로고침하면 사라집니다. 녹음 파일은 서버로 전송되지 않습니다.
- **새 스크립트로 연습 시작**하면 이전 스크립트의 항목별 결과와 반복 이력이 초기화되지만 **약한 단어 누적 통계는 남습니다**.
- **약한 단어 → 기록 지우기**는 약한 단어 통계만 삭제합니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 브라우저·기기 사용 등에 따라 기록이 유지되지 않을 수 있습니다. 자동 클라우드 동기화 기능은 없습니다.

## 문제 해결

| 증상 | 확인할 사항 |
|---|---|
| 마이크 버튼이 작동하지 않음 | HTTPS 또는 `http://localhost`로 접속했는지, 사이트 마이크 권한이 허용되었는지 확인하세요. |
| 음성인식을 지원하지 않는다는 안내 | 브라우저를 최신 버전으로 업데이트하고 Chrome·Edge 또는 기기에서 지원되는 Safari로 시도하세요. 지원 범위는 기기별로 다릅니다. |
| 말했는데 아무것도 인식되지 않음 | 마이크 입력 장치, 주변 소음, 음성인식 서비스 연결 상태를 확인하고 다시 읽어보세요. iPad·iPhone에서 녹음 기능을 켠 뒤 인식이 잘 안 된다면 **설정 → 내 목소리 녹음 → 끄기**로 바꿔 보세요. |
| 내 목소리 듣기 버튼이 나타나지 않음 | 녹음 설정이 켜져 있는지, 마이크 녹음 권한이 허용되었는지 확인하세요. 버튼은 방금 읽은 문장·단어에서만 나타납니다. |
| 잘 읽었는데 낮은 점수가 나옴 | 인식 오류 또는 단어 분리·정렬의 영향일 수 있습니다. 동음이의어로 인식된 경우라면 `HOMOPHONES` 목록에 추가할 수 있습니다. **원문 듣기**와 비교하고 다시 시도하세요. |
| Google 음성 재생 실패 | API 키, Text-to-Speech API 활성화, 결제 설정, API 키 제한, 네트워크 연결 및 Safari 자동 재생 정책을 확인하세요. |
| 기록이 사라짐 | 브라우저 저장소 또는 개인정보 보호 설정, 다른 브라우저·기기 사용 여부를 확인하세요. |

## 기술 구성 및 유의사항

- **HTML + CSS + JavaScript** 단일 파일
- 음성인식: 브라우저 `SpeechRecognition` / `webkitSpeechRecognition` API
- 내 목소리 녹음: 브라우저 `getUserMedia` + `MediaRecorder` API
- 원문 읽기: 브라우저 `SpeechSynthesis` API 또는 Google Cloud Text-to-Speech REST API
- 비교: 단어 정규화(숫자 0–20, 일부 약어, 동음이의어) 및 최소 편집 거리 기반 정렬
- 별도 계정, 자체 서버, 외부 JavaScript 라이브러리는 필요하지 않습니다. 단, **브라우저 음성인식 서비스는 자체적으로 네트워크 통신을 사용할 수 있으므로 완전한 오프라인·음성 데이터 비전송 방식으로 간주하면 안 됩니다.**
- **동음이의어 목록 수정 시 주의:** right/light처럼 연습 대상이 되는 최소대립쌍은 절대 같은 묶음에 넣지 마세요. 넣으면 해당 발음 차이를 판정할 수 없게 됩니다.
- CSV 내보내기, 자동 다음 문장 이동, 별도 마이크 테스트, 녹음 파일 저장, 계정·클라우드 동기화 기능은 제공하지 않습니다.
